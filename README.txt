EL GAME — première version
1. Ouvre index.html dans un navigateur pour prévisualiser le site.
2. Les quatre mini-jeux inclus sont des prototypes originaux jouables dans le navigateur.
3. Pour publier gratuitement, importe le contenu de ce dossier dans un dépôt GitHub puis active GitHub Pages.
4. Pour ajouter un jeu : ajoute son fichier HTML dans games/, puis ajoute une entrée dans le tableau `data` de script.js (id = nom du fichier sans .html).
5. Les jeux Godot ne fonctionnent pas automatiquement sur le web : il faut les exporter en version Web/HTML5 et les tester.
6. Cette version est une base de départ, pas encore publiée sur Internet ni indexée par Google.
